# aten.copy.t

## 1. OP 概述
### 1.1 算子原型
```
torch.ops.aten.copy.t(
    t[](a) self
) -> t[]
```

### 1.2 算子功能
返回泛型列表 `self` 的拷贝：创建一个新的列表对象，元素与原列表相同（浅拷贝，元素对象本身共享），是列表层面的拷贝操作，不是 Tensor 数据拷贝。

## 2. OP 规格
### 2.1 参数说明
| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| `self` | `t[]` | 待拷贝的泛型列表，t 为泛型元素类型 |
| 返回值 | `t[]` | 新的列表对象，元素与 `self` 相同 |

### 2.2 支持规格
该重载依赖 TorchScript 泛型列表类型，不定义 GPU/NPU Tensor dtype 和 shape 支持矩阵。

### 2.3 特殊限制说明
> 拷贝为浅拷贝，只复制列表容器本身，不复制元素对象。TorchScript 架构已被社区弃用，该历史重载不纳入 Inductor 设备 Tensor 用例验证。

## 3. 遗留问题
该算子操作 TorchScript 泛型列表 `t[]`，TorchScript 架构已被社区弃用，无法构造用例。
