# aten.mul.left_t

## 1. OP 概述
### 1.1 算子原型
```
torch.ops.aten.mul.left_t(t[] l, int n) -> t[]
```

### 1.2 算子功能
`aten.mul.left_t` 对输入列表 `l` 执行列表重复操作，将列表元素按顺序重复 `n` 次并返回新列表。该重载不执行 Tensor 逐元素乘法。

## 2. OP 规格
### 2.1 参数说明
| 参数名 | 类型 | 说明 |
| ------------- | ----------------- | -------------------------------------------------------------- |
| `l` | `t[]` | 待重复的输入列表 |
| `n` | `int` | 列表重复次数 |
| 返回值 | `t[]` | 将 `l` 重复 `n` 次后的新列表 |

### 2.2 支持规格
#### 2.2.1 DataType 支持
该重载输入为列表和整数，不涉及 Tensor dtype，DataType 支持表不适用。

#### 2.2.2 Shape 支持
1、`l` 为一维 Python 列表，不涉及 Tensor shape 泛化。

2、输入参数 `l` 的元素类型为泛型 `t`，参数 `n` 为 Python `int`；返回列表元素类型与 `l` 相同。

### 2.3 特殊限制说明
> 该重载实际为列表重复算子，不属于 Tensor 算子，不能生成 Triton kernel；仅维护 schema 和行为规格。
